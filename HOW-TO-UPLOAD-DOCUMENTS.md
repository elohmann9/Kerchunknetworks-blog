# How to Upload Documents to GitHub Using Working Copy (iPad)

## Quick Reference Guide

### Upload a New Document to Existing Repository

1. **Open Working Copy** on your iPad
2. **Select your repository** from the list
3. **Add the file:**
   - Tap the **folder icon** or **repository name** at the top
   - Tap the **+** button (usually top right)
   - Select **"Add files"** or **"Import"**
   - Choose your document from the Files app
   - The file appears in your repository

4. **Commit your changes:**
   - Tap the **Status** section (shows uncommitted changes)
   - Review the new file
   - Tap **"Commit"**
   - Add a descriptive message (e.g., "Add quarterly report")
   - Tap **"Commit"** to confirm

5. **Push to GitHub:**
   - Tap the **upload/push arrow** (usually in toolbar)
   - Tap **"Push"**
   - Wait for confirmation
   - Your document is now on GitHub!

## Create a New Repository

### Option 1: Create on GitHub Website First (Recommended)

1. Go to **github.com** in Safari
2. Sign in to your account
3. Click the **+** icon (top right) → **"New repository"**
4. Fill in:
   - Repository name (e.g., "work-documents")
   - Description (optional)
   - Public or Private
   - Initialize with README (recommended)
5. Click **"Create repository"**

6. **Clone to Working Copy:**
   - Open Working Copy
   - Tap **+** → **"Clone repository"**
   - Search for your new repository
   - Select it to download

### Option 2: Create Directly in Working Copy

1. Open Working Copy
2. Tap the **+** button
3. Select **"Create repository"**
4. Enter repository name
5. Choose location
6. Tap **"Create"**
7. Push to GitHub:
   - Tap repository settings (gear icon)
   - Add remote → GitHub
   - Follow prompts to create on GitHub

## Edit Existing Documents

1. Open Working Copy
2. Navigate to the file
3. Tap the file to view
4. Tap **"Edit"** or the pencil icon
5. Make your changes
6. Tap **"Done"** or **"Save"**
7. **Commit** (as described above)
8. **Push** to upload changes

---

## Common Tasks

### Check What Changed Before Committing
- Tap **"Status"** in your repository
- Review all changed files
- Tap a file to see differences (red = removed, green = added)

### Pull Latest Changes from GitHub
- Tap the **download arrow**
- Tap **"Pull"**
- Your local copy updates with remote changes

### Switch Branches
- Tap the **branch name** (e.g., "main")
- Select different branch from list
- Or create new branch with **+** button

### Resolve Conflicts
- Working Copy highlights conflicted files
- Tap the file
- Choose: "Use Ours", "Use Theirs", or manually edit
- Commit once resolved

## Tips

- **Commit often** with clear messages
- **Pull before pushing** to avoid conflicts
- Use **descriptive filenames** (no spaces, use hyphens)
- Keep **related files together** in directories
- **Sync regularly** to back up your work

---

## Troubleshooting

**Problem: Can't push**
- Make sure you're connected to internet
- Pull first to get latest changes
- Check for conflicts

**Problem: File not appearing**
- Make sure you committed the changes
- Check you're on the right branch
- Refresh the repository

**Problem: Authentication failed**
- Check your GitHub credentials in Working Copy settings
- May need to regenerate Personal Access Token
