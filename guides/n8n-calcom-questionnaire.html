🤖 Cal.com + n8n Automation Guide

Auto-send your questionnaire when a client books a meeting

📋 How this works: n8n allows you to bypass Cal.com's paid workflows by using free Webhooks. When someone books on Cal.com, it sends a signal to n8n, which automatically emails the client your questionnaire link.

Step 1: Set up the n8n Workflow

The "Copy & Paste" Method

n8n has an incredible feature where you can literally copy code and paste it directly onto your workflow canvas to instantly generate the nodes.

  1. Open your n8n dashboard and create a New Workflow.
  2. Copy the JSON code block below.
  3. Click anywhere on the blank n8n canvas and press Cmd+V (Mac) or Ctrl+V (Windows) to paste it.
{
  "nodes": [
    {
      "parameters": {
        "httpMethod": "POST",
        "path": "calcom-booking",
        "responseMode": "onReceived",
        "options": {}
      },
      "id": "1",
      "name": "Cal.com Webhook",
      "type": "n8n-nodes-base.webhook",
      "typeVersion": 1,
      "position": [250, 300],
      "webhookId": "kerchunk-calcom-book"
    },
    {
      "parameters": {
        "fromEmail": "admin@kerchunknetworks.com",
        "toEmail": "={{ $json.body.payload.attendees[0].email }}",
        "subject": "Kerchunk Networks - Please complete your network questionnaire",
        "text": "Hi {{$json.body.payload.attendees[0].name}},\n\nThanks for booking a consultation with Kerchunk Networks!\n\nTo ensure we make the most of our time together, please take 5-10 minutes to complete our network assessment questionnaire prior to our meeting. This will help us review your current setup and prepare an accurate game plan.\n\nClick here to fill out the form:\nhttps://kerchunknetworks.com/questionnaire/index.html\n\nTalk to you soon,\n\nErik\nKerchunk Networks",
        "options": {}
      },
      "id": "2",
      "name": "Send Email",
      "type": "n8n-nodes-base.emailSend",
      "typeVersion": 2,
      "position": [450, 300]
    }
  ],
  "connections": {
    "Cal.com Webhook": {
      "main": [
        [
          {
            "node": "Send Email",
            "type": "main",
            "index": 0
          }
        ]
      ]
    }
  }
}

Step 2: Configure the Email Node in n8n

  1. Double click the Send Email node that appeared on your canvas.
  2. You need to set up your Email Credentials (if you haven't already). Click Create New Credential.
  3. If you use Google Workspace/Gmail, you can use the built-in Gmail node instead of standard SMTP. If you use Microsoft 365, you can use the Outlook node!
  4. Ensure the "From Email" matches your actual email address.

Step 3: Connect Cal.com to n8n

  1. In n8n, double click the Cal.com Webhook node.
  2. Look for the Production URL and copy it to your clipboard.
  3. Log in to your Cal.com dashboard.
  4. Go to Settings > Developer > Webhooks.
  5. Click New Webhook.
  6. Paste your n8n Production URL into the Subscriber URL box.
  7. Under "Triggers", uncheck everything EXCEPT "Booking Created".
  8. Click Save.

Step 4: Activate & Test

  1. In n8n, flip the toggle in the top right corner from Inactive to Active.
  2. Save your workflow.
  3. Go to your public Cal.com page and book a dummy meeting with your own personal email address.
  4. Check your personal email inbox—you should receive the automated questionnaire link instantly!
