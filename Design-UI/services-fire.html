Cradlepoint Installs

The Cradlepoint R1900 and IBR1700 are the standard for fire apparatus networking. Proper install means clean cable runs, antenna placement that actually works, and configuration locked down for public safety use — not a default out-of-the-box setup.

  • Antenna placement and RF optimization
  • APN configuration for AT&T FirstNet and Verizon
  • Tablet Command and CAD system integration

  • On-site installation — we come to you

Fleet Management

  • NetCloud Manager setup and group configuration
  • Real-time online/offline status for every unit
  • Remote configuration and firmware pushes
  • Alert routing for offline events
  • Usage monitoring and data plan tracking
  • Monthly fleet health reporting

Dual SIM & Starlink Failover

A single carrier going down shouldn't take your apparatus dark. Dual SIM keeps you on air when one carrier fails. Add Starlink at the station and you have a third path — critical for rural departments where LTE coverage isn't a guarantee.

  • Dual SIM configuration — AT&T and Verizon simultaneously
  • Automatic failover with zero manual intervention
  • Starlink installation and station integration
  • Load balancing across available connections
  • Failover testing and validation
  • Coverage mapping for your response area
